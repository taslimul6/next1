# TypeScript Assignment 1

This repository contains solutions and study notes for a Level 2 TypeScript assignment. It covers core TypeScript concepts through practical exercises and explanatory blog posts.

## File Structure

```
├── solutions.ts          # TypeScript solutions for assignment exercises
├── type-vs-interface.md  # Blog post comparing `type` vs `interface`
├── type-narrowing.md     # Blog post explaining type narrowing in TypeScript
└── README.md             # This file — repository overview
```

## Topics Covered

- Type narrowing (`typeof`, `in` operator)
- Union and intersection types
- Generics (`<T>`)
- Read-only tuples and arrays
- Classes, inheritance, and access modifiers
- Async/await and Promise handling
